👑 마스터 사용법

1
대시보드에서 전체 생산 현황 확인
2
승인 대기 메뉴에서 신규 회원 승인
3
오더 등록 → 벤더 배정
4
선적 확정 → 선적 요청된 오더의 선적수량/ETD/초기 불량 확정
5
입고 일정표 → 내부 공유용 인쇄

🏭 벤더 사용법

1
회원가입 후 마스터 승인 대기
2
공장 관리 → 공장 정보 + CAPA 등록
3
오더 현황 → 생산 공장/라인 + 생산수량 입력
4
CUT→ARTWORK→SEW→FINISH 4단계 체크 완료 → [선적 요청] 버튼 클릭

3
[불량 추가] 버튼 → 추가 불량 수량 입력 → 누적 반영
