👑 마스터 사용법

1
대시보드에서 전체 생산 현황 확인
2
승인 대기 메뉴에서 신규 회원 승인
3
오더 등록 → 벤더 배정
4
선적 요청 관리 → 벤더 부킹 요청 확정/거절
5
입고 일정표 → 내부 공유용 인쇄

🏭 벤더 사용법

1
회원가입 후 마스터 승인 대기
2
공장 관리 → 공장 정보 + CAPA 등록
3
오더 현황 → 생산 공장/라인 + 생산수량 입력
4
생산 완료분 → 부분 출고 부킹 요청

🔍 CS팀 사용법

1
회원가입 후 마스터 승인 대기
2
CS 클레임 메뉴 → 스타일 검색
3
최종 불량 수량 입력 → 자동 반영

🛍️ MD 사용법

1
회원가입 후 마스터 승인 대기
2
오더 등록 → 벤더에게 스타일 배정
3
대시보드에서 전체 현황 조회 (읽기 전용)
